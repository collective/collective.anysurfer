# collective.anysurfer

[![Tests](https://github.com/collective/collective.anysurfer/actions/workflows/test-matrix.yml/badge.svg)](https://github.com/collective/collective.anysurfer/actions/workflows/test-matrix.yml)
[![Meta](https://github.com/collective/collective.anysurfer/actions/workflows/meta.yml/badge.svg)](https://github.com/collective/collective.anysurfer/actions/workflows/meta.yml)

This package adds [Anysurfer](https://anysurfer.be/fr) support to Plone.
Anysurfer is a Belgian accessibility standard equivalent to WCAG 2.0 A.

This package is totally transparent for the user.
It fixes various accessibility issues in Plone, in standard features,
content types, body texts, forms, search results, ...

It also overrides Plone Accessibility info to allow its edition through
the Anysurfer control panel.


## Features

1. Adds missing page titles for views / skins / 404 error page
2. Add search results count in H1 and move H1 to the top
3. Add search results count in page title
4. Fixes News item image alt
5. Removes empty `<ul>` lists
6. Allows empty image alt
7. Fixes 'Required' labels html position
8. Replace Plone `replacetag="h2"` by real tag
9. Replace default Accessibility info with a multilingual editable text
10. Replace "nav" by "div" for breadcrumb


## Compatibility

Version 2.x supports Plone 6.1 on Python 3.10 to 3.13, and Plone 6.2 on Python
3.10 to 3.14.
For Plone 4.3 to 6.0, use collective.anysurfer 1.4.x.

The search page and breadcrumb overrides still use the Plone 5 markup.

## Installation

Add `collective.anysurfer` to the dependencies of your project
(`pyproject.toml`, or `requirements.txt` with the Plone constraints), install
it, restart Plone and activate the add-on in *Site Setup* > *Add-ons*. This
also installs collective.z3cform.datagridfield.

The accessibility text is edited in *Site Setup* > *Anysurfer*.


## Development

Requires [uv](https://docs.astral.sh/uv/). This installs Plone 6.2.3 in `.venv`
(use `PLONE_VERSION=6.1.6 make install` for another version) and the prek git
hook:

```shell
make install
make start          # Plone on http://localhost:8080 (admin / admin)
```

Create a Classic UI site from the browser, then activate collective.anysurfer.

### Tests

Tests run through tox, as the CI does:

```shell
make test                                   # Plone 6.2.3
uvx --with tox-uv tox -e py312-plone61      # one Plone / Python combination
make test-all                               # lint, every combination, dependencies
```

Without tox (the tests check French translations, so compile the `.mo` files):

```shell
zope_i18n_compile_mo_files=true .venv/bin/zope-testrunner --test-path=src -s collective.anysurfer
```

### Lint

```shell
make check          # format then lint (pyupgrade, isort, black, zpretty, flake8...)
```

### Translations

```shell
make i18n           # rebuild the collective.anysurfer catalog
```

`.editorconfig`, `.flake8`, `.gitignore`, `.pre-commit-config.yaml`, `tox.ini`,
`.github/` and the tool sections of `pyproject.toml` are generated by
[plone.meta](https://github.com/plone/meta): change `.meta.toml`, then run
`uvx --from plone.meta config-package --no-commit --branch current .`.
